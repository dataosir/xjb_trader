# F10 · 观察池

## 1. 背景与目标

未写成可买计划的候选进入观察池，盘后复核强弱与超时清理，避免「落选即失忆」。

## 2. 用户故事 / 场景

- `seed-plan` 自动纳入观察轨。  
- `watch --review` 或随 `review` 一并复核。  
- 手动 `--add` / `--rm`。

## 3. 功能范围

**In**

- 多轨道（`KNOWN_TRACKS`，默认观察轨）  
- 纳入 / 剔除 / 盘后复核 / 超时 prune  
- 与种子报告、持仓对照协同展示  

**Out**

- 观察池直接升格写计划（须回到 F03/F07 流程）  
- 自动买入  

## 4. 主流程与边界

1. 入池携带档位、分数、板块戳记等快照。  
2. 复核更新涨跌与状态。  
3. `--no-prune` 可跳过超时清理。  

**边界**：观察轨历史胜率可能优于「可买」——观察池是重要对照样本源，不可当垃圾场清空不落盘。

## 5. 关键配置键

| 键域 | 用途 |
|---|---|
| 观察超时天数 / 轨道名 | watch_pool 相关配置 |

## 6. 代码锚点

- `tea/portfolio/watch_pool.py`  
- `tea/runtime/runner.py` · `close_review`（含观察池）  
- CLI：`tea watch [--review] [--add] [--rm] [--track]`

## 7. 验收标准

- [ ] 原子写 `watch_pool.json`  
- [ ] `review` 默认会碰观察池（除非关闭）
