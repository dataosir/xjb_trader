# F01 · 市场天气（道）

## 1. 背景与目标

把全市场状态压缩为可执行的「天气」：情绪分 → 周期 → 交易姿态 → 仓位乘数，供门禁与筛选共用。默认答案偏防守。

## 2. 用户故事 / 场景

- 作为交易者，我在 13:30 跑 `weather`，决定今日是否值得继续选股。  
- 作为 `seed-plan` / `run`，系统需同一套天气对象，避免口径分裂。

## 3. 功能范围

**In**

- 情绪分六项加减（涨跌比、最高连板、上证 MA20 位置与涨跌、热点板块数、前 5 板块均涨等）  
- 周期与姿态推导；仓位乘数夹紧  
- 数据缺口摘要与横幅（指数/板块/涨跌家数/网络失败）  
- 短时缓存（如 120s，可 `--refresh`）

**Out**

- 个股打分（属 F04）  
- 直接写计划或下单  

## 4. 主流程与边界

1. 拉取指数 / 涨跌家数 / 板块强度（经 F14）。  
2. `sentiment` 计分；`timing` 映射时段与姿态。  
3. 缺口写入 `data_gap_summary`，供种子报告备注。  

**边界**：源抖动导致整维归零 → 分数漂；必须可见提示，不得静默当「天气很好」。  
**屏上「新开」**：`allow_new_label` — 空仓/高潮 → `禁止`；防守 → `未硬禁（防守缩手）`；进攻 → `未硬禁`（未触发硬闸 ≠ 鼓励买入）。

## 5. 关键配置键

| 键（示例） | 用途 |
|---|---|
| `market.*` | 超时、重试、数据源 |
| 情绪/姿态相关阈值 | 见 `config_store.DEFAULTS` 中 sentiment/strategy 段 |

## 6. 代码锚点

- `tea/analysis/sentiment.py` — 情绪分、缺口摘要  
- `tea/core/timing.py` — 时段 / 姿态  
- `tea/runtime/runner.py` · `weather`  
- CLI：`tea weather [--refresh]`

## 7. 验收标准

- [ ] `tea weather` 输出情绪分、周期、姿态、乘数  
- [ ] 有缺口时种子结束出现 ⚠️ 横幅（与 `format_data_gap_banner` 一致）  
- [ ] `--refresh` 可绕过短缓存  
- [ ] 相关 selftest 断言与公式同步  

## 8. 已知缺口 / 待迭代

- 大盘缺失时共振大盘维归零，复盘难（工程噪音，见路线图）  
- 消息面维长期 0/0，等于死维（跨 F04）
