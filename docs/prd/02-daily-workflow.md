## 1. 日时间线（默认）

| 时刻 | 动作 | 命令 / 菜单 | 相关功能 |
|---|---|---|---|
| ~13:30 | 观察盘面强弱 | `weather` / 菜单 `1` | F01 |
| **~14:30** | 种子四步流 → 写次日计划（收尾可自动轻量回填） | `seed-plan` / 菜单 `3` | F03 / F04 / F06 / F07 / F11 |
| 可选 | 胜率影子扫描（对比） | `winrate-scan` / 复盘工具▸ | F05 |
| ~14:35 / 09:35 | 计划复核（要素变动 → 整单作废） | `plan-check` / 计划▸ | F07 |
| 收盘后 / 隔夜 | 跟涨回填 + 观察池 + 当日累积 | `review` / 菜单 `8`（进菜单亦可自动轻量回填） | F11 / F10 |
| **T+1 14:00–14:45** | 唯一买入窗口，执行计划内标的 | `run <代码>` / 准入▸ | F02 / F08 / F09 |
| 盘中任意（演练） | 只算不买 | `eval <代码>` / 准入▸ | F04 / F08 |
| 持仓管理 | 确认仓 / 平仓 / 流水 | `add-confirm` / `close` / `trades` / 持仓▸ | F09 |

> 窗口类限制可用 `--any-time`（仅演练）或配置调整；生产纪律默认开启。

## 3. 周节奏

| 频率 | 动作 | 命令 |
|---|---|---|
| **每日** | `seed-plan`（含自动轻量回填） | 菜单 `3` |
| **每周 ≥1 次** | 全量 `review`：回填 + 观察池；看**样本缺口看板**与影子桶 T+3 | 菜单 `8` / `tea review` |
| 持续 | 跟涨经验 + 缺口/影子对照 | `followthrough` / 复盘工具▸ |
| 每周五（建议） | 纪律自查 + 归因 | `weekly` |
| 策略迭代前 | 对齐 backlog 样本门槛（影子 T+3>0≥60%；低吸≥30） | `05-roadmap-backlog.md` |

### 攒数据运营清单（A 轮）

1. 每天跑通种子；确认收尾有「回填 x / 仍待 y」或已齐。  
2. 每周至少一次全量复核，把「待 T+3」压下去（交易日不够属正常）。  
3. 看缺口看板：`lowbuy`、因子覆盖、新闸门后可买条数——**不据此放松门槛**。  
4. 影子桶只对照，不交易；达标门槛见配置 `t3_up_target`（默认 60%）。  
5. 低吸空池：只读 diag，本轮不放宽落盘、不买入。

## 5. 推荐日循环（可买口径纠偏后）

1. `seed-plan`：预期「可买」更少（突破+过热禁买）；收尾自动轻量回填，控制台只留一行数量摘要。  
2. `plan-check`：确认板块/要素未漂移。  
3. 次日窗口 `run`：计划内代码；通过后手动下单，再用 `pos-add` 或引擎登记路径补登。  
4. 隔日/盘后仍建议跑一次全量 `review`（观察池 + 累积）；轻量自动回填不替代它。  
5. 可选 `winrate-scan`：影子通道对照，**不写计划**。

## 6. 空仓日也有价值

- `accum`：解释「为何没交易」  
- `trace`：淘汰链路  
- 低吸空池：`lowbuy_pool_diag` 逐关归因（见 F06）  
- 数据缺口横幅：种子结束时醒目提示（见 CHANGELOG）
