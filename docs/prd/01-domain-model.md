# 01 · 领域模型

## 1. 三层框架（道 / 法 / 术）

| 层 | 含义 | 典型输出 | 否决效果 |
|---|---|---|---|
| **道** | 市场天气是否允许交易 | 情绪分、周期、姿态、仓位乘数 | 空仓/高潮易分歧等 → 禁买 |
| **法** | 纪律是否允许这一笔 | 计划绑定、窗口、限额、冷却 | 任一门禁失败 → 禁止评估/开仓 |
| **术** | 个股是否够资格 | 身份、9 分共振、VETO、ATR/R:R | 否决或分数不足 → 不可买 |

关系：**串联否决**。下层通过不能覆盖上层否决。

## 2. 核心业务对象

| 对象 | 持久化 | 说明 |
|---|---|---|
| 交易计划 Plan | `data/trade_plan.json` | 次日可执行的纪律锚点；元素变动可整单作废 |
| 单日门禁状态 | `data/daily_state.json` | 评估次数、新开次数、同标复筛等 |
| 资金与持仓 | `data/capital_state.json` | 总资金、持仓、试错/确认仓 |
| 观察池 | `data/watch_pool.json` | 未写成可买计划的候选跟踪 |
| 交易流水 | `data/trades.json` | 开平仓登记 |
| 种子记录 | `data/seed_records.jsonl`（跟涨） | 候选落盘 + T+n 回填 |
| 落选追溯 | `data/seed_trace.jsonl` | 每步淘汰原因 |
| 当日累积 | `data/accumulator.jsonl` | 「为何今天没交易」事件流 |
| 影子板块 | `data/shadow_pool.json` 等 | 板块动量观察 |

写入一律**原子写**（`.tmp` → `rename`）。

## 3. 候选轨道与标签

| 标签 / 轨道 | 含义 | 是否写计划 |
|---|---|---|
| **可买（追高）** | 规则通道过共振 + 过可买硬闸 | 是（`seed-plan`） |
| **观察轨** | 入围但被闸门/分数降级 | 否；可进观察池 |
| **低吸观察（启动前夕）** | `TIER_EVE` + `lowbuy=True` | **否**（只攒样本） |
| **胜率可买（影子）** | `mode=winrate`，`winrate_score` 达标 | **否**（只对比） |

## 4. 档位（Tier）

| 常量 | 名称 | 用途 |
|---|---|---|
| `TIER_STRICT` | 严格档 | 主追涨窗 |
| `TIER_RELAXED` | 热点降级档 | 热点放宽涨幅上沿 |
| `TIER_MOMENTUM` | 强势跟涨档 | 更高涨幅窗 |
| `TIER_SPROUT` | 萌芽窗口 | 三档皆空时兜底扫描 |
| `TIER_EVE` | 前夕观察 / 低吸 | 1%~3% 窗，不写计划 |

## 5. 评分与闸门概念

| 概念 | 定义要点 |
|---|---|
| **情绪分** | 基准 50、上限 100；涨跌比、连板、上证 MA20、热点板块等加减 |
| **9 分共振** | 板块 / 大盘 / 消息 / 市值 / 量价 / 止损结构等维；过动态门槛才 PASS |
| **VETO** | 一票否决（硬/软）；硬否决不可买 |
| **ATR 止损止盈** | 止损 clamp；含滑点 R:R ≥ `strategy.min_odds`（当前默认 2） |
| **winrate_score** | 按历史胜率因素加权的影子分；可买硬闸可要求 ≥ 门槛 |
| **可买硬闸 `_winrate_gate`** | 突破/过热禁买、板块排名、入选一致性、`winrate_score` 等 |

## 6. 仓位模型（3/7 灰度）

- **试错仓 ~30%**：`run` 通过后登记  
- **确认仓 ~70%**：突破确认后 `add-confirm` 补足  
- 仓位乘数由姿态/天气夹紧（典型区间约 [0.25, 1.0]，以配置为准）

## 7. 会话与阶段结果

`run` 使用 `phases.session.Session`；阶段返回值统一为 `OK / REJECT / ABORT`（`phases.results`），阶段间不互相调用，只读写 Session。

## 8. 配置命名空间（节选）

| 前缀 | 职责 |
|---|---|
| `strategy.*` | 门槛、闸门开关、min_odds |
| `seed.*` | 种子扫描窗、板块放宽、低吸池 |
| `scoring.*` | 共振维权重/满分封顶 |
| `winrate.*` | 胜率通道门槛 |
| `market.*` | 数据源链、超时、代理 |
| `gates.*` / 门禁相关 | 窗口、限额、冷却（见 F02） |

完整默认值见 `tea/config/config_store.py` 的 `DEFAULTS`。
