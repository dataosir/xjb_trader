# 00 · 产品概览

## 1. 产品定位

**XJB_TRADE（TEA）** 是面向个人交易者的 A 股**交易准入引擎**，不是选股软件、不是行情终端、不是自动交易系统。

引擎默认回答是「不买」。只有当 **道（市场天气）、法（纪律门禁）、术（个股共振）** 三层**同时点头**，才放行一次开仓评估/登记。

> 一句话：不预测涨跌，只回答——**今天这一笔，够不够资格下手？**

三层是**串联否决**，不是加权投票：任一层否决，整笔作废。

## 2. 目标用户与场景

| 角色 | 场景 |
|---|---|
| 一人公司 / 个人交易者 | 盘中按纪律选次日计划；T+1 窗口内执行计划内标的 |
| 纪律研究者 | 用种子落盘 + T+n 回填验证「可买」口径是否有效 |
| 贡献者 | 改公式必须同步 `selftest`，保持零依赖与不下单边界 |

## 3. 核心价值主张

1. **计划绑定**：无有效计划或代码不在计划内 → 禁止评估/买入。  
2. **时间纪律**：买入窗口默认仅 14:00–14:45；种子扫描锚定 14:30 附近。  
3. **可审计**：落盘原子写；种子追溯、跟涨样本、当日累积可回答「为何没交易 / 为何落选」。  
4. **可回滚**：策略闸门多为配置开关（如 `strategy.winrate_gate_enabled`）。

## 4. 非目标（明确不做）

| 不做 | 原因 |
|---|---|
| 对接券商 / 自动下单 | 产品边界；下单必须人手动完成 |
| 一键跳过计划/窗口/限额 | 纪律即产品意义 |
| 引入重量级第三方运行时依赖 | 标准库优先；`requests` 仅可选加速 |
| 保证盈利 | `BUY` 仅表示过纪律条件，非收益承诺 |
| （当前）低吸买入上线 | 阶段 1 只攒样本；见 F06 / LOWBUY_PLAN |
| （当前）胜率先验调节门槛 | 阶段 B HOLD；见 F05 / WINRATE_PRIOR |

## 5. 成功度量（产品层）

| 指标 | 说明 | 当前参照 |
|---|---|---|
| T+1 跟涨胜率 | 涨幅 ≥3% 计胜；盈亏平衡约需 ≥33%（R:R≈2） | 种子样本见 CHANGELOG / 路线图 |
| 「可买」轨 vs 观察轨 | 可买应不劣于观察；否则口径错误 | 历史曾出现可买劣于观察 |
| selftest 全绿 | 公式与断言同步 | CI + 本地 `tea selftest` |
| 样本字段完整度 | `bias_ma20` / `lowbuy` / `winrate_score` 等可归因 | F11 |

## 6. 系统边界图（逻辑）

```

                ↓
           次日计划(F07) ←→ 门禁(F02)
                ↓
           run Phase1–4(F08) → 持仓/资金(F09) / 观察池(F10)
                ↓
           review 回填(F11) → 报告统计(F12)
配置(F13) · 质量(F15) 横切全链路
```
