## 一、为什么现在不做（样本盘点）

对 `seed_records.jsonl` 当前数据盘点（2026-08-24）：

| 项 | 值 |
| --- | --- |
| 总记录 | 71 |
| 已回填 win/loss | 62（13 胜 / 49 负 = 21%） |
| 阶段 B 所需分桶（板块排名桶 × 阶段 × 档位 × 身份分桶） | 33 个桶 |
| **≥30 样本的桶** | **0 个** |
| 最大单桶样本 | 9 |

结论：**经验胜率先验要求每个桶 ≥30 样本才可信，当前最大桶仅 9 样本，远不够。** 强行上线会过拟合噪声（9 个样本的胜率可能是 0% 或 100%，都不可信）。

单维度里只有「板块排名 >5」（34 样本）和「热点降级档」（46 样本）勉强够，但阶段 B 需要的是**交叉桶**（多维度组合），否则先验太粗、退化成阶段 A 的硬规则。

## 二、阶段 B 技术方案（HOLD，待样本达标后实现）

### 2.1 目标

用 `followthrough` 聚合的**真实 T+1 胜率**做「先验分」，调节通过门槛，让「历史高胜率特征」的票更容易过、低胜率更难过。

### 2.2 数据源与聚合维度

扩展 `followthrough.aggregate`，从现在的 `阶段×档位×轨道` 增加：

| 维度 | 分桶 |
| --- | --- |
| 板块排名 `sector_rank` | 1-3 / 4-5 / 6-8 / >8 |
| 身份分 `identity_score` | <75 / 75-85 / 85-93 / 93+ |
| 涨幅 `chg_pct` | <3% / 3-5% / 5-7% / 7-9% / >9% |
| 阶段 `stage` | 萌芽 / 突破 / 过热 |
| 档位 `tier` | 严格档 / 热点降级档 / 强势跟涨档 |

（这些字段已在 seed_records 中，`sector_rank`/`identity_score`/`chg_pct` 本来就有，`bias_ma20` 等刚补。）

### 2.3 先验函数

```python
def winrate_prior(ev: dict, cfg) -> Optional[float]:
    """查候选所属桶的历史 T+1 胜率；样本 < min_samples(30) 返回 None（不调节）。"""
    key = bucket_of(ev)          # (板块排名桶, 阶段, 档位, 身份分桶, 涨幅桶)
    slot = aggregate(cfg).get(key)
    if not slot or slot["n"] < int(cfg.get("followthrough.min_samples", 8)):
        return None
    return slot["rate"]           # T+1 胜率
```

> 注：`min_samples` 现在是 8，阶段 B 需单独用更严的阈值（建议 30），避免 8 个样本就敢调节门槛。

### 2.4 门槛调节

在 `preflight.effective_threshold` 末尾接入（先验用候选特征查，不参与杂毛/龙头/防守的语义）：

```python
prior = winrate_prior(ev_feature, cfg)
if prior is not None:
    if prior >= 0.50:
        th -= 1
        notes.append(f"胜率先验 {prior:.0%}（N={n}）→ 门槛 -1")
    elif prior < 0.20:
        th += 1
        notes.append(f"胜率先验 {prior:.0%}（N={n}）→ 门槛 +1")
```

> 50% / 20% 是初步阈值，等样本达标后再用数据回测校准。

### 2.5 可解释性

- 门槛 notes 留痕（如上），`scan_details` / SEED 报告可见「为什么门槛是 7 而不是 6」。
- 每个候选的 `winrate_prior` 落盘到 seed_records，供下一轮归因。

## 四、阶段 A 与阶段 B 的关系

- 阶段 A（已落地）：**硬门槛砍输家**——板块排名 >5 或 突破+排名>3 → 降级观察。零样本依赖、可回滚。
- 阶段 B（HOLD）：**经验先验调门槛**——用真实胜率微调门槛，需要足够样本才可信。

两者不冲突：阶段 A 先保证「不选明显输家」，阶段 B 再让「赢家更容易过」。等阶段 B 上线且样本充足后，可视回测结果把阶段 A 的部分硬门槛替换成阶段 B 的连续先验。
