## 二、胜率现状与归因发现

### 2.1 现状

- 种子记录 71 条，已回填 T+1 的 **58 条**：**11 胜 / 47 负 = 19%**（口径：T+1 涨幅 ≥3% 计胜）。
- 实盘 0 笔盈利（持仓全为手动单），系统从未自主选出过赚钱的票。

### 2.2 关键发现（按可信度排序）

| 维度 | 分组 | 胜率 / 表现 |
| --- | --- | --- |
| **板块排名**（最强信号，跨 T+1/T+3/T+5 单调） | 1~3 | **50%** / T+5 +3.31% |
| | 4~5 | 28~33% |
| | 6~8 | 6~17% |
| | 9~15 | **0~8%** / T+5 **-7.32%** |
| **共振分（反了）** | 4 分 | **44%**（最好） |
| | 5 分 | 9%（最差） |
| | 6 分（可买） | 12% |
| **轨道（反了）** | 可买 0/4 | **0%**，T+3 -5.33% |
| | 观察轨（被拒） | **33%** |
| **阶段** | 突破 | 6%（1/17），T+3 -5.22% |
| **档位 × 板块** | 热点降级档 × 排名 9-15 | 8%（n=25，最大输家桶） |
| **身份分** | 75~85 | 5%；85~93 为 33%；93+ 回落到 25% |

### 2.3 根因一句话

> 系统在「**追高中游板块（6~15 名）的强势股**」：板块门槛太松放进了输家，而「乖离>8%」等扣分又在反向惩罚真正强势的票，导致 4 分（被拒）反而跑赢 6 分（可买）。

## 三、核心目标与原则

1. **胜率是第一位**：先解决「选错票」，再谈「仓位/乘数/风控」。
2. **数据先行**：样本 <30 笔的归因结论不可信；每次调参必须有 `param_change` 留痕 + 前后胜率对比。
3. **只动有数据支撑的维度**：目前只有「板块排名」跨周期单调可信，优先围绕它收紧；其余维度等数据。
4. **反对硬闸、反对拍脑袋阈值**：用分级扣分/分级加权表达风险，而不是 0/1 一刀切。

## 四、后续迭代规划（三阶段）

### 阶段 1 · 数据积累（现在 ~ 2 周）

目标：把「能归因的样本」攒到 **≥30 条/分组**，并补齐缺失字段。

- [ ] **每日跑 `review` / `close-review` 回填 T+N**：现在 58 条里 T+3 只回了 41、T+5 只回了 26，先补齐。
- [ ] **补跟涨样本字段**（下一批，见 §5.3）：`amount_yi`（成交额）、`cap_yi`（市值）、`rank_pct`（板块内排名占比）、`odds/sl_pct/tp_pct`（盈亏比结构）、`veto_labels`（否决原因）。
- [ ] **跑 2 周观察收紧板块门槛后的新样本**：确认排名 1-5 板块的票是否真的把胜率拉起来。
- [ ] **shadow_pool 回填**：`shadow_pool.json` 已记最强板块，回填这些板块次日涨跌，验证「板块动量持续性」。

### 阶段 2 · 逐因子归因（样本 ≥30 后）

目标：用数据回答下面几个待验证假设，据此改权重。

| 待验证假设 | 数据来源 |
| --- | --- |
| 「乖离>8%」是否在反向惩罚强势票（4 分赢家都是高乖离） | `bias_ma20` × 胜率 |
| 当日涨幅最优区间（现在 3~5% 最好 27%，5~7% 仅 14%） | `chg_pct` 细分桶 × 胜率 |
| 身份分 85~93 是否优于 93+（最热龙头反而追高） | `identity_score` 分桶 × 胜率 |
| 分时位置（追高程度）是否负向 | `intraday` × 胜率 |
| 每一维共振分的胜率贡献（找出「加分反而降胜率」的维度） | `scoring_dims` 逐维 × 胜率 |

### 阶段 3 · 评分体系重构（验证后）

目标：把「共振分反了」的根因修掉。

- [ ] **板块强度维加细分**：rank 1-3 → 2 分、4-5 → 1 分、>5 → 0（现在 rank≤3 与 rank≤8 不再同分）。
- [ ] **重配「大盘趋势」权重**：若归因显示 MA20 斜率比位置更有效，则提高斜率权重、降低位置权重。
- [ ] **审查「量价结构」扣分项**：`bias_penalty_pct`（乖离>8% 扣分）大概率方向错了，据数据反转或取消。
- [x] **重估 6 分门槛与「可买」口径**：可买 0/4 跑输观察轨，门槛这 1-2 分选错了方向；在样本够前，至少「可买」不允许出现在排名 >5 的板块。
  （2026-08-25：突破一律否决 + `winrate_score` 可买硬门槛 + 入选板块一致性校验已接入；共振权重重构仍等阶段 2 数据。）
