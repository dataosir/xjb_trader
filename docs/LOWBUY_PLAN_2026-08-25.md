# 低吸（启动前夕）技术方案 · TODO

> 状态：**规划中，未实现**。本文是「从追涨扩展到低吸」的技术方案与待办清单。
> 配套：当前程序是「追涨」策略（涨幅窗口 3% 起），低吸是「启动前夕买入」（1~3%）。
> 关联：`docs/WINRATE_ROADMAP_2026-08-24.md`（胜率迭代路线）、`docs/WINRATE_PRIOR_PLAN_2026-08-24.md`（阶段 B 先验）。

## 一、目标与动机

- **问题**：追涨策略只买「今天已涨 3%+」的票，天然错过「启动前夕」；且实测可买 0/5、T+1 -2.11%（后继乏力），被拒的强势票反而赢。
- **目标**：新增一条「低吸」通道——在 1~3% 涨幅窗口（启动前夕）选票，吃「鱼身」而非「鱼尾」。
- **原则**：数据先行。低吸票的胜率/特征尚未验证，**先落盘积累样本，再决定是否上线买入**。

## 三、核心设计（三阶段）

### 阶段 1：把「前夕观察」升级为「前夕候选」（只积累，不买入）

- [x] 保留 `TIER_EVE` 窗口（1.0~3.0%），但把「永不写计划」改为「落盘 + 回填，暂不写计划」。（文案已改「低吸观察 · 暂不写计划，积累样本」）
- [x] 确认前夕候选的**板块归属**：低吸不追 TOP1-3 已涨停的板块，而应瞄准「排名 3~10、正在升温（板块涨幅 2~4%、无涨停或 1 家涨停）」的板块——这类板块才是「启动前夕」。（`lowbuy_sector_pool` 已实现）
- [x] 给前夕候选打上「低吸特征」标签落盘：`bias_ma20`、`vol_ratio`、`intraday`、`ma_bull`、`above_ma20`、`sector_rank`、`sector_chg`（这些字段已在 seed_records 里）。（`lowbuy=True` 标签已加）

### 阶段 2：用回填样本验证「低吸票长什么样」（≥30 条后）

- [ ] 统计前夕观察轨 vs 追涨轨（可买/启动待定）的 T+1/T+3/T+5 胜率与均涨。
- [ ] 验证低吸票的候选特征假设：
  - [ ] **量能**：低吸吃「启动前量能低谷」——缩量（量比 <1）是否比放量更优？
  - [ ] **位置**：分时低位（<50%）是否比贴高更优？
  - [ ] **乖离**：低乖离（<5%，贴近 MA20）是否比高乖离更优？
  - [ ] **形态**：均线收敛（MA5≈MA10≈MA20）或缩量回踩 MA5，是否比多头发散更优？
  - [ ] **板块**：排名 3~10 升温板块，是否比排名 1~2 涨停板块更适合低吸？
- [ ] 计算低吸票需要的最低盈亏比：1~3% 的票大部分不会启动（胜率天然低），需要 R:R≥3 甚至 5 才划算（`odds_calc` 已支持，`min_odds` 需上调）。

### 阶段 3：上线「低吸买入」档位（验证通过后）

- [ ] 新增 `TIER_LOWBUY` 档位（或复用 `TIER_EVE` 改「可写计划」）。
- [ ] 低吸票独立选股条件（不复用追涨的身份分/系统分门槛）：
  - [ ] 板块：排名 3~10 且升温（待阶段 2 定阈值）。
  - [ ] 量价：缩量回踩/均线收敛（待阶段 2 定阈值）。
  - [ ] 位置：分时低位（待阶段 2 定阈值）。
  - [ ] 盈亏比：`min_odds` 上调至 3~5。
- [ ] 持仓周期：低吸吃鱼身需 2~5 天，`followthrough` 的 T+1 计胜阈值（当前 3%）可能需单独设（或按 T+3 计胜）。

## 四、数据积累（前置条件，最高优先）

- [ ] 每日跑 `seed-plan`：确认 `TIER_EVE` 窗口在「无追涨候选」时也能产出前夕候选（当前逻辑：三档全空才扫萌芽窗口，前夕观察是独立 `eve_scan`，需确认其在空仓日也落盘）。
- [ ] 每日跑 `review`：回填前夕观察轨的 T+1/T+3/T+5。
- [ ] 每周盘点前夕样本数：达到 ≥30 条才进入阶段 2。

## 五、风险提示

1. **胜率天然低**：1~3% 的票大部分不会启动，低吸通道的胜率可能只有 10~20%，必须靠高盈亏比（R:R≥3~5）而不是高胜率赚钱。
2. **持仓周期拉长**：低吸吃鱼身要 2~5 天，与当前 T+1 追涨的「次日卖出」节奏不同，需要单独的跟踪/止损逻辑（`watch_pool` 的持仓时限、`followthrough` 的计胜周期都要调）。
3. **不要急着上线买入**：在 ≥30 条前夕样本验证之前，低吸通道只落盘、不写计划、不买入，避免「拍脑袋转策略」。

## 六、待办优先级

1. **P0**：阶段 1 的「前夕候选落盘 + 特征标签」——让低吸样本开始积累。
2. **P0**：阶段 1 的「确认前夕候选板块归属（排名 3~10 升温）」——否则低吸样本和追涨样本混在一起，无法归因。
3. **P1**：阶段 2 的验证（≥30 条后）。
4. **P2**：阶段 3 的上线。
