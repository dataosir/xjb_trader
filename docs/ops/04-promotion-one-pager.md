## 一句话

**A 股交易准入引擎** — 默认「不买」；道法术三层串联否决；不荐股、不自动下单。

## 适合谁

- ✅ 有规则仍冲动开仓的交易者  
- ✅ 想学纪律引擎怎么实现的开发者  
- ❌ 要荐股 / 跟单 / 稳赚的人  

## 发布前检查

- [ ] 文案含免责声明（学习用途、非投资建议）  
- [ ] **无**收益战绩、胜率、必涨措辞  
- [ ] 强调 EMPTY / 空仓是设计  
- [ ] 链到 README 快速开始 + `selftest`
