# 04 · 证据周 Scorecard（Ops-2）

> **频率**：每周日（建议）；**主帽**：交易员。  
> **目的**：把「攒证据」从体感变成可对照的数字表，支撑方案 A（rank 5→3）~09-18 复盘与闸门微调决策。  
> **原则**：对照验收 ≠ 可买放行；样本未达门槛前禁止拍脑袋调参。

---

## 1. 本周数据来源（复制前跑一遍）

| 动作 | 命令 / 入口 | 取什么 |
|---|---|---|
| 缺口看板 | `tea review` 或菜单 `8` | 待 T+1 / 待 T+3、新闸后可买 n |
| 跟涨汇总 | `tea review` 输出 `followthrough` 段 | 全样本 T+1≥3%、T+3>0 |
| 影子桶 | 同上 `shadow_t3` 或周五 `tea weekly` | 萌芽 / 前三非突破 / 合计 T+3>0 |
| 运营纪律 | `logs/daily/seed/`、`review/` 日录 | 本周 seed-plan / review 是否漏跑 |
| 错误 | `grep YYYY-MM-DD logs/error.log` 或 `[TEA运维]` 邮件 | launchd / 未捕获异常 |

## 4. 与方案 A（rank 5→3）的每周必看

方案 A 已于 **2026-09-09** 启动（见 [`project-state.md`](../project-state.md)）。每周日填表时额外记录：

1. **post-change** rank≤3 的 T+3>0 是否仍 ≥60%？  
2. 新闸后可买本周新增几条？EMPTY 是否可接受？  
3. rank 4–5 是否出现「被错杀」的有效个案（仅记录，不据此放宽）？

复盘锚点：**~2026-09-18**；详细背景见 [`archive/SHADOW_BUCKET_PLAN_2026-09-04.md`](../archive/SHADOW_BUCKET_PLAN_2026-09-04.md)。
