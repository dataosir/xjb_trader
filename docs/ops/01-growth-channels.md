# 01 · 推广渠道与目标受众

> 运营层框架。TEA 当前以**个人/小团队交易纪律工具**为主；本页记录受众假设与可选渠道，避免口头约定丢失。

---

## 1. 产品一句话

A 股**交易准入引擎**：计划绑定 + 道法术串联否决；默认「不买」，不自动下单。

## 2. 目标受众（假设）

| 画像 | 痛点 | 我们提供的价值 |
|---|---|---|
| 主观交易者（一人公司主用户） | 冲动开仓、无计划、无复盘 | 强制计划窗口与门禁 |
| 规则型量化爱好者 | 想要可审计的筛选链路 | 可配置阈值 + 种子落盘归因 |
| 开源学习者 | 想看零依赖纪律引擎怎么写 | README + selftest + MIT |

**非受众**：要自动跟单/券商对接的人；要「荐股必涨」的人。

## 3. 渠道草稿（待验证）

| 渠道 | 状态 | 备注 |
|---|---|---|
| GitHub 仓库 + README | 已有 | 主分发面 |
| 开源社区 / 技术向短文 | 未做 | 强调「准入而非荐股」与免责声明 |
| 小范围熟人试用 | 可选 | 收集反馈进 `02-user-feedback.md` |

## 4. 信息安全与合规口吻

对外文案必须保留：学习/纪律研究用途、非投资建议、不自动下单、行情第三方可能失效。
