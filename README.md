# XJB_TRADE (TEA) — A 股交易准入引擎

[![CI](https://github.com/dataosir/xjb_trader/actions/workflows/ci.yml/badge.svg)](https://github.com/dataosir/xjb_trader/actions/workflows/ci.yml)
[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![自测](https://img.shields.io/badge/selftest-151%2F151-brightgreen.svg)](#十离线自测)

> 计划你的交易，交易你的计划。宁可空仓，不强行凑票。

这不是选股软件，是**准入引擎**。它的默认答案是"不买"，只有当道（市场天气）、法（纪律门禁）、术（个股共振）三层同时点头，才会放行一次开仓。

引擎不预测涨跌，只回答一个问题：**今天这一笔，够不够资格下手？**

---

## ⚠️ 风险与免责声明

**本项目仅用于个人学习与交易纪律研究，不构成任何投资建议。**

- 引擎输出的 `BUY` 只表示“本笔符合预设纪律条件”，**不是盈利保证**，也不预测价格。
- 股市有风险，入市需谨慎。**你的盈亏完全由你自己负责**，作者不对任何交易结果承担责任。
- 行情数据来自第三方公开接口，**可能延迟、出错或随时停服**。下单前请以券商客户端为准。
- 引擎**不对接任何券商交易接口，不会自动下单**。所有买卖需你手动执行。
- 请自觉控制请求频率，避免给数据提供方造成压力。

首次使用强烈建议：先用 `eval`（只算不买）空跑至少两周，确认引擎的判断与你的认知一致后，再考虑小资金实盘。

## 一、三层框架

| 层 | 职责 | 模块 |
|---|---|---|
| **道** | 市场天气：情绪分 → 周期 → 交易姿态 → 仓位乘数 | `sentiment.py` `timing.py` |
| **法** | 纪律门禁：计划绑定、时间窗、单日限额、连亏冷却、仓位与期望值 | `gates.py` `plan.py` `portfolio.py` `expectancy.py` |
| **术** | 个股评分：身份判定、9 分共振、ATR 止损止盈、VETO 一票否决 | `identity.py` `preflight.py` `veto.py` `screener.py` |

三层是**串联否决**关系，不是加权投票 —— 任一层否决，整笔作废。

## 二、安装与运行

零第三方依赖，只需 Python 3.8+（仅用标准库 `urllib` / `json` / `concurrent.futures`）。已在 Linux / macOS / Windows 与 Python 3.8 至 3.13 上通过 CI。

### 方式一：一键启动脚本（最省事）

```bash
git clone https://github.com/dataosir/xjb_trader.git
cd xjb_trader

./run.sh                    # 进入数字菜单
./run.sh selftest           # 离线自测
./run.sh eval 600519        # 子命令原样透传
```

Windows 用 `run.bat`，可直接双击：

```bat
run.bat
run.bat selftest
```

脚本只做三件事：找到 3.8+ 的解释器（找不到就明确告诉你缺什么，而不是报一堆堆栈）、把数据目录锁在仓库根目录、把参数原样交给引擎。不装包，不建虚拟环境。

两个可选环境变量：`TEA_PYTHON` 指定解释器（如 `TEA_PYTHON=python3.12 ./run.sh`）；`TEA_HOME` 指定数据目录，你设了就以你的为准。

> 锁定数据目录这一步不是多余的：引擎默认把配置与持仓写在**当前工作目录**，不锁的话从不同路径启动会生出好几套互不相干的数据。

### 方式二：安装为命令

```bash
git clone https://github.com/dataosir/xjb_trader.git
cd xjb_trader
pip install .

tea                         # 进入数字菜单
tea --help                  # 查看全部子命令
```

想让抓取更稳（连接复用）可装上可选的 `requests`；不装则自动回退 `urllib`，功能不变：

```bash
pip install ".[fast]"
```

### 方式三：不安装，直接跑源码

```bash
git clone https://github.com/dataosir/xjb_trader.git
cd xjb_trader

python3 -m tea              # 进入数字菜单（推荐）
python3 -m tea --help       # 查看全部子命令
python3 -m tea selftest     # 离线自测，不联网，验证公式与规格对齐
```

下文命令统一写 `tea xxx`，换成 `python3 -m tea xxx` 或 `./run.sh xxx` 完全等价。

### 初始配置

首次运行会建立 `data/`；`tea_config.json`（**362 个可调参数**）在你首次改配置时落盘，`reports/` 在首次出报告时建立。想先看默认值：

```bash
tea config count      # 参数总数与配置文件路径
tea config list       # 全部参数（点号路径）
tea config set strategy.pass_threshold 7
```

开始用之前先告诉引擎你的本金，否则可用资金为 0、算不出仓位：

```bash
tea capital 100000
tea status            # 确认门禁计数 / 计划 / 持仓
```

数据目录可用环境变量改写，便于多账户或沙箱：

```bash
TEA_HOME=~/my_trade tea
```

> `tea_config.json`、`data/`、`reports/` 已写入 `.gitignore`。它们含你的本金、持仓、代理池等私有信息，**不要提交到公开仓库**。

### 数字菜单

不带子命令直接运行就进菜单。菜单**默认只列此刻该做的四件事**，按当前时段自动变：

```
XJB_TRADE (TEA) 1.0.0　2026-08-03 14:10 | 买入窗口(14:00-14:45) | 买入窗口=开
  此刻（买入窗口(14:00-14:45)）建议：
   3. 单标的准入评估（Phase1→4）
   7. 查看交易计划
   5. 种子扫描 + 写次日计划（14:30）
  10. 持仓 / 资金
   m. 展开全部 20 项
   q. 退出　│　1-20 任意编号都可直接输入
```

| 输入 | 作用 |
|---|---|
| `1`–`20` | 直接执行对应功能。**编号永不变**，没列出来的也能输 |
| `m` | 展开全部 20 项（按道法 / 准入 / 计划 / 持仓 / 复盘 / 工具 分组） |
| `c` | 收起，回到四条建议 |
| 直接回车 | 重印菜单（不算选错） |
| `q` | 退出 |

为什么默认不全列：同一时刻真正有意义的操作从来不超过四个。非交易日只能复盘和演练，买入窗口外再怎么评估也会被门禁拦回——把 20 项平铺在眼前只会让人每次重新读一遍。

## 三、每日时间线

引擎的纪律是**跨日闭环**：T 日收盘前选种子写计划，T+1 日只执行计划。当天临时起意的票一律买不进去。

| 时刻 | 动作 | 命令 |
|---|---|---|
| 13:30 | 观察扫描，看盘面强弱 | `weather` |
| **14:30** | **种子四步流 → 写次日计划** | `seed-plan` |
| 14:35 | 计划复核（任一要素变动 → 整单作废） | `plan-check` |
| 收盘后 | 跟涨回填 + 观察池复核 + 当日累积 | `review` |
| T+1 10:00 | 隔夜复核，计划是否还成立 | `plan-check` |
| **T+1 14:00–14:45** | **唯一买入窗口，执行计划** | `run <代码>` |
| 每周五 | 周复盘：纪律自查 + 归因 | `weekly` |

> 为什么买入窗口是 14:00–14:45：尾盘方向已明、当日情绪已定型，避免上午被假突破反复骗手。

## 五、核心公式

### 情绪分（道，基准 50 / 上限 100）

涨跌比、最高连板、上证 MA20 位置与涨跌幅、热点板块数、前 5 板块均涨 —— 六项加减得分，映射到周期：

```
冰点 <35 │ 修复 <50 │ 发酵 <70 │ 主升 ≥70 │ 高潮 │ 退潮
```

姿态：`空仓`（<40 或冰点，禁止新开）→ `防守`（<55 或 MA20 下）→ `进攻`。

**冰点降仓**：最高连板 ≤3 且涨跌比 <35% → 半仓乘数强制 ×0.25。

**高潮易分歧**：前 5 板块均涨 ≥7% → 禁止新开（人人赚钱时离场）。

### 9 分共振（术）

| 维度 | 满分 | 判据 |
|---|---|---|
| ① 板块强度 | 2 | 板块排名 ≤8 且涨停 ≥2；板块内前 10% 再 +1（封顶 2）；后 50% -1 |
| ② 大盘趋势 | 1 | 上证上涨 **且** 在 MA20 上方 |
| ③ 消息面 | 1 | 有明确催化 |
| ④ 市值区间 | 2 | 50~300 亿最佳；<30 亿归零；>500 亿仅 1 分 |
| ⑤ 量价结构 | 2 | 放量上涨 + 均线多头；换手 >20%、量比异常等逐项扣分 |
| ⑥ 止损结构 | 1 | 止损 ≤8% 且 止损/ATR ≤2.5 且 R:R ≥3 |

**动态门槛**：基准 6，杂毛 +1，样本不足 +1，防守姿态 +1；种子龙头 -1（下限 6）。

### 身份判定（100 分制，6 维）

板块内排名、板块排名、个股 vs 板块涨幅、板块涨停跟涨、市值、均线。

```
龙头 ≥70 │ 跟风 ≥45 │ 杂毛 <45
```

**≥2 个负面 flag 强制降为杂毛** —— 分数好看但硬伤多的票不给通行证。

**热点板块相对跟涨**：极热板块（≥6%）内，相对系数 `个股涨幅/板块涨幅` 落在 0.42~0.90 → +18（跟得上但没透支）；板块前排 + 板块内前 40% 额外 +12。

### ATR 止损止盈（ATR 优先）

```
止损% = clamp(ATR% × 1.5, 2%, 8%)，硬顶 6%
止盈% = min(ATR% × 3, 15%)
```

**含滑点 R:R**（买入 +0.5% / 止损 -0.5%，只做悲观假设）：

```
R:R = (目标价 - 买入价×1.005) / (买入价×1.005 - 止损价×0.995)
```

要求 `R:R ≥ 3`；不足则抬高止盈反推，抬到 15% 上限仍不够 → 直接否决。

打平胜率 `= 1/(1+R:R)`。期望值 `E[R] = p̂ × odds − (1 − p̂)`，历史样本不足时按默认胜率 0.40 并标记 `样本不足`。

### 仓位（3/7 灰度确认制）

```
半仓额度   = 总资金 × 50% × 乘数
总股数     = floor(半仓额度 / (价格 × 100)) × 100
灰度仓 30% ──突破确认──> 确认仓 70%
乘数 = 情绪乘数 × 期望值乘数 × 跟涨乘数，夹紧 [0.25, 1.0]
```

先用 30% 试错，方向对了再补 70%。错了只亏 3 成。

### VETO 一票否决（术）

| 硬否决（直接毙） | 软否决（进观察轨，不买） |
|---|---|
| 涨停区 ≥9.5% | 接近涨停 ≥9% |
| ST / *ST | 龙头乖离 >20% |
| 换手 >25% | 普通股乖离 >15% |
| 无板块交易权限 | 分时位置 >75%（龙头 >85%） |
| 乖离 MA20 >30% | |
| 分时位置 ≥95% | |

20cm 板（创业板 / 科创板）阈值等比 ×2。

## 六、纪律硬约束

这几条**不接受 FORCE**，是引擎存在的理由：

1. **计划绑定** —— 今日无有效计划，或代码不在计划内 → 禁止评估、禁止买入。
2. **买入窗口** —— 非 14:00–14:45 → 禁止新开。
3. **单日限额** —— 每日最多新开 1 笔、评估 5 次、同一标的复筛 2 次。
4. **上证 MA20 下方** → 禁止评估新开。
5. **姿态空仓 / 高潮易分歧** → 禁止买入。
6. **连亏冷却** —— 连续亏损达阈值 → 强制冷却期。
7. **VETO 硬否决 / 共振分不足 / R:R <3** → 禁止买入。

## 十、离线自测

```bash
python3 -m tea selftest
```

自测**不联网**，用构造行情跑全链路。关键点：每一项断言都在测试内**按规格独立重算一遍**再和引擎比对，所以它能抓住"实现和规格分叉"，而不只是"代码没崩"。

覆盖范围：情绪分逐项复算 + 冰点降仓、身份 6 维 + 分数夹紧 + 杂毛强制降级、ATR(14) + 止损止盈 + 含滑点 R:R + 反推止盈、9 分共振六维逐项 + 扣分项、VETO 全部阈值边界（含 20cm ×2 放大与权限）、仓位与期望值公式、三道门禁 7 条规则、种子四步流、行情解析量级（fltt=2 不再缩放，含尺度无关的涨幅自洽断言）、clist 翻页（精确涨跌家数 + 板块成分不被前 100 名截断）、涨停池按交易日回退、菜单分组与时段建议、`run_once` 端到端（BUY → 灰度仓 → 补确认仓 → 平仓 → 门禁拦截当日第二次评估）。

## 十一、验收对照

| 验收项 | 入口 | 自动断言 |
|---|---|---|
| 输入代码 → 行情 → 板块/身份/9分 → BUY/REJECT | `run` `eval` | ✓ 端到端 |
| seed-plan → TOP 板块 → 三档筛选 → VETO → 预审 → 写计划 | `seed-plan` | ✓ 四步流 |
| plan-check → 快照对比检测变动 → 作废/有效 | `plan-check` | ✓ 计划有效性与 `executed` 标记 |
| 市场天气 → 情绪评分 → 姿态判定 → 冰点降仓 | `weather` | ✓ 逐项复算 + ×0.25 |
| 门禁：时间窗/计划绑定/MA20/单日限额 | `gate` `status` | ✓ 7 条规则 |
| VETO：涨停/乖离/分时高位/换手/ST | 内置于评估 | ✓ 15 个阈值边界 |
| 仓位：3/7 灰度 + 半仓乘数（情绪×期望×跟涨） | `pos` `add-confirm` | ✓ 公式 + 整手向下取整 |
| 观察池：纳入/剔除/回踩就绪 闭环 | `watch` `review` | — 命令已通，未单独断言 |
| 身份判定：龙头/跟风/杂毛 + 杂毛预警抬门槛 | 内置于评估 | ✓ 6 维 + 门槛 6→7 |
| 防封：随机UA/Referer/延时/代理池/缓存 | `data/fetcher.py` | — 自测离线，不覆盖网络层 |

两项标 `—` 的是实现完成但没有自动断言：防封属网络行为，离线自测按设计不触网；观察池闭环由 `seed-plan` → `review` 贯通，建议实盘第一周人工比对一次。

> 注意：自测全程离线，因此**东财接口的真实连通性（URL、字段映射、防封节奏）尚未经过验证**。公式是确定的，网络层只能证明结构完整。建议盘中先跑 `tea weather` 与 `tea eval <代码>` 实际验一下。
